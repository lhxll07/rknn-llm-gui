# 宣传页

这是一个可直接在浏览器中播放和录制的 HTML5 宣传页，默认时长约 60 秒。

## 本地预览

在项目根目录启动一个静态服务器：

```bash
python3 -m http.server 8080 --directory promo
```

打开：<http://127.0.0.1:8080>

也可以直接打开 `promo/index.html`，但浏览器可能限制本地音频和视频加载，推荐使用静态服务器。

## 添加素材

将真实工作台录屏放到：

```text
promo/assets/workbench-demo.mp4
```

将曼波旁白放到：

```text
promo/assets/voiceover.mp3
```

没有素材时页面会显示可播放的演示占位，不影响动画预览。录屏和旁白已被 Git 忽略，不会误提交到仓库。

## 录制建议

- 使用 16:9、1920×1080、30 FPS
- 浏览器全屏打开页面
- 先点击页面播放，再开始 OBS 录制
- 真实录屏片段使用与页面相同的 16:9 比例
- B 站发布前再添加字幕和封面
