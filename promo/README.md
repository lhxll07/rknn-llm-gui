# 宣传页

这是一个可直接在浏览器中播放和录制的 HTML5 宣传页，默认时长约 51 秒。

## 本地预览

在项目根目录启动一个静态服务器：

```bash
python3 -m http.server 8080 --directory promo
```

打开：<http://127.0.0.1:8080>

也可以直接打开 `promo/index.html`，但浏览器可能限制本地音频和视频加载，推荐使用静态服务器。

## 添加素材

将四段录屏和旁白放到 `promo/assets/`：

```text
environment.mp4       # 环境检查
text-convert.mp4      # 文本模型转换
vision-convert.mp4    # 视觉模型转换
output.mp4            # 输出文件
voiceover.mp3         # 曼波旁白
```

页面会在动画后自动淡入对应录屏。录屏和旁白已被 Git 忽略，不会误提交到仓库。

## 时间与变速

旁白按约 51 秒编排，四段录屏会在对应场景中自动静音播放：

```text
text-convert.mp4   2.46 倍
vision-convert.mp4 2.10 倍
environment.mp4    原速，结束后停留最后一帧
output.mp4         2.50 倍
```

录屏会裁掉浏览器顶部工具栏，并对画面中的本地路径做轻度模糊处理，避免把地址栏、用户名和绝对路径直接放进成片。

## 录制建议

- 使用 16:9、1920×1080、30 FPS
- 预览时点击“重新播放”按钮，或直接按空格键从头播放
- 真实录屏片段使用与页面相同的 16:9 比例
- B 站发布前再添加字幕和封面

## OBS 录制

推荐使用 OBS 的“浏览器源”，不要使用“窗口采集”。

1. 启动本地静态服务器。
2. 在 OBS 添加“浏览器源”。
3. 地址填写 `http://127.0.0.1:8080/?record=1&autoplay=1`。
4. 宽度设置为 `1920`，高度设置为 `1080`。
5. 如果有旁白文件，在 OBS 中启用浏览器源音频。
6. 开始录制。

录制模式会自动播放并隐藏网页底部控制条，因此不会录进网页按钮、浏览器地址栏或网页黑边。
